# Tablero Biotina

Página con el semáforo de los anuncios de Biotina (Meta Ads): qué sacar, qué mantener y qué escalar.
Se publica con GitHub Pages desde `site/`. Los números salen de `site/datos.json`, que arma `scripts/armar.js`
a partir de lo que devuelve Meta (`meta.json`, no se sube) y de las ventas reales por anuncio.
Las reglas y la lista de anuncios están en `scripts/config.json`.
